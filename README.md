# IPostMap SDK document

Documentation website được tạo bằng [docsify](https://docsify.js.org/)

## Setup

```bash
npm install --global serve
```

## Preview

Tại thư mục gốc của ipostmap.github.io, chạy lệnh sau:

```bash
serve .
```
