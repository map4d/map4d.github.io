# Travel Mode :id=api-travel-mode

`MFTravelMode` enum

```swift
enum MFTravelMode: UInt {
    case car
    case bike
    case foot
    case motorcycle
}
```

Định nghĩa các phương thức di chuyển được hỗ trợ:
  - MFTravelModeCar: ô tô
  - MFTravelModeBike: xe đạp
  - MFTravelModeFoot: đi bộ
  - MFTravelModeMotorcycle: xe máy
